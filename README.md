
# PySpark

This project showcases basic data analysis using **PySpark** on the Titanic dataset. It includes:

- Initializing Spark locally
- Loading and inspecting CSV data
- Performing simple transformations and filtering using Spark DataFrames

## 🛠 Tech Stack

- Python
- PySpark
- Jupyter Notebook
- Titanic Dataset (CSV)

## 🔧 Setup (Windows)

```bash
pip install pyspark findspark pandas
choco install openjdk  # if Java not installed
```

## 📁 Dataset

[Titanic CSV Dataset](https://raw.githubusercontent.com/datasciencedojo/datasets/master/titanic.csv)
