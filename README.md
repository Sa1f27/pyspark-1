
# ⚡PySpark

This project uses **Apache Spark with PySpark** to analyze the Titanic dataset — a step beyond traditional Pandas-based workflows.

---

## 💡 Why PySpark?

PySpark is the Python API for Apache Spark — a powerful engine for big data processing. Unlike Pandas, which runs on a single core, **PySpark can scale across multiple CPUs or machines**, making it ideal for handling larger datasets efficiently.

---

## 🔍 What PySpark Enabled in This Project

- ✅ Faster data loading and transformation using Spark DataFrames  
- ✅ Schema-based operations similar to SQL  
- ✅ Better handling of large datasets (even beyond memory limits)  
- ✅ Spark's lazy evaluation helped optimize performance  
- ✅ Ready for scaling to cluster-based processing

---

## 🛠 Tech Used

- Python  
- PySpark  
- Jupyter Notebook  
- Titanic CSV dataset
